## Lessons

- Fine-grained GitHub PATs are scoped to specific repos at creation time — newly created repos aren't automatically included. Use `gh auth token` for e2e tests.
- containerd's content store is content-addressed — you can't overwrite an image tag by reimporting if the old blobs still exist. Use `crictl rmi` to properly purge.
- Bitnami retires short version tags (e.g., `1.31`) without notice. Always pin to a full version or use `:latest`.
- HTTPRoutes for gateway-attached services MUST deploy to the cluster where the gateway lives — embedding them in workload overlays deploys to vclusters where the gateway doesn't exist.
