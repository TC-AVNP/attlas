## Lessons

- The dotfiles install.sh --vm flag controls skill symlinking — any new Pi role (router, basic-node) that needs skills must pass this flag in its Ansible playbook
- Google Cloud OAuth redirect URIs can't be managed via gcloud CLI — always requires manual console intervention
