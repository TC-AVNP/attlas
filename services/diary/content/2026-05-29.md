## Project summaries

### neko

New hello-world service created from scratch. Minimal Go server on port 7699 serving a single HTML page with pure CSS cat animations — three cats (orange tabby chasing yarn, gray cat watching, black cat pouncing) with blinking eyes, wagging tails, and floating paw prints. No auth, no database. Deployed at neko.attlas.uk behind Caddy.
