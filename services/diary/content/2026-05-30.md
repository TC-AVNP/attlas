## Lessons

- Cloudflare free plan wildcards only cover one subdomain level — `*.attlas.uk` matches `foo.attlas.uk` but NOT `api.foo.attlas.uk`
- GCP VMs need `--can-ip-forward` for pod egress — without it, GCP silently drops packets from pod IPs
- iptables PREROUTING REDIRECT without `-i <interface>` captures pod egress traffic too — breaks cert-manager, ArgoCD, everything needing internet
- Bundling Helm sub-charts (Istio, ArgoCD, vclusters) in a parent chart creates CRD ordering and naming conflicts — better to install separately via a script
- Let's Encrypt has no wildcard level limit — you can issue certs for `*.foo.attlas.uk` freely via DNS-01, unlike Cloudflare's edge which requires paid ACM
- When the Helm chart creates CRD-dependent resources (Gateway, Certificate, ApplicationSet), the CRDs must be installed BEFORE the chart — use an install script that orchestrates the order
